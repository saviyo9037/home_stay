# Malaram — Kerala Homestay Website

A responsive homestay showcase website built with Next.js App Router, TypeScript and custom CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Preview notes

This is a visual booking-enquiry prototype. The homestay name, room details, photos, location coordinates and indicative prices are sample content and should be replaced with the actual property's information before launch. The enquiry form opens WhatsApp; no booking database, availability calendar, payment processing or admin dashboard is connected.
